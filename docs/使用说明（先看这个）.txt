========================================
   DS鲸鱼娘 桌面宠物   使用说明
========================================

【怎么用】

双击  DS鲸鱼娘桌宠.exe   就完事了。

不用安装、不用解压、不用装 Python，什么都没有。
她就出现在屏幕右下角。

  注意：双击之后要等几秒才会出现（一般 2~4 秒，
  第一次打开、或者杀毒软件正在扫描时会久一些）。
  这个程序是单个文件的，启动时要先把自己解压一下，
  所以比普通软件慢一点 —— 别以为没反应就狂点，
  点第二下不会让它变快。


  另外：她同一时间只会跑一个。要是她已经开着了，你再双击
  一次图标不会开出第二个，而是把已经在跑的那个叫到最前面
  —— 藏起来了、或者开着穿透，都是这么叫回来。


========================================
【第一次打开会弹蓝色警告，这是正常的，不是病毒】
========================================

Windows 会弹出「Windows 已保护你的电脑」。

原因：这个程序没有买数字签名证书，Windows 对这类程序一律
这么提示，跟有没有病毒无关。

解决办法：
     点「更多信息」 → 再点「仍要运行」

只需要点这一次，以后打开就不再提示了。

如果杀毒软件报毒：同样是误报（这类打包程序经常被误杀），
加信任或白名单即可。不放心的话可以把 exe 传到 virustotal.com 查。


========================================
【运行环境】
========================================

  · 64 位的 Windows 10 或 Windows 11
  · 需要显卡驱动支持 OpenGL（正常电脑都有）

不支持的：32 位系统、Windows 7/8、Mac、手机。


========================================
【怎么操作】
========================================

· 鼠标移到哪，她就看哪 —— 眼睛和头会跟着鼠标转
· 按住左键拖动        → 换位置（会记住，下次打开还在原地）
· 左键单击            → 随机做一个动作（表情 / 换装 / 动画都可能）
                        有的动作要道具，她会先自己把道具拿出来再演 ——
                        抽到「自拍」会先掏手机再举起来拍，抽到「番茄酱」
                        会先在桌上摆一盘蛋包饭再挤，抽到「手机换色」也是
                        先掏手机。这类动作演完连道具一起收走，不会留在桌上
· 右键                → 打开菜单，可以从清单里指定做某个动作
· 托盘小图标左键单击  → 把桌宠叫到最前面
· 再双击一次程序图标  → 不管她是藏起来了、还是开着穿透，
                        都给你叫回来（比找托盘图标稳）
· 什么都不用做        → 她自己每隔半分钟做一个动作，演几秒自己收回，
                        不影响你手动搭好的搭配（你一动她，计时重新开始）
                        她抽的和左键单击是同一池，所以也会自己掏出手机自拍、
                        自己摆盘挤番茄酱 —— 摆出来的东西她也会自己收干净，
                        不会在你桌上留一盘菜


========================================
【右键菜单每一项是什么意思】
========================================

动作
    点开是一份完整的动作清单，51 个动作全在里面，点哪个做哪个 ——
    记不住快捷键就用这个。分三组，组名括号里写了点下去会怎样：

      表情（一次一条）               脸上的表情，一次只留一条
      装扮与道具（可以和表情一起挂）  头顶的鲸鱼、桌上的蛋包饭、手里的画笔…
      动画                           一次性播完的动画

    表情是「开关」：前面打了勾的表示正开着，再点一下就是关掉。
    点另一条表情时，上一条会自动关掉，不会叠在一起 —— 所以想换表情
    直接点新的那条就行，不需要先归位。

    （早先的版本会叠加，那样会出现「吐舌的嘴留在下一张表情上」这种
      脏画面，所以改掉了。）

    装扮不一样：点表情不会把装扮顶掉，装扮之间也不会互相顶掉。
    所以可以「脸红 + 头顶鲸鱼 + 桌上摆个蛋包饭」一起挂着，之后换表情、
    换动画都不影响那两样道具。

    这个组里有两条是例外：「手机换色」和「魔爪换色」。它们得先把道具
    弄出来才能换（手机要「开盖」掏出来，魔爪要先摆一罐），所以点下去是
    一段演完就收的表演 —— 掏手机、换个色、收起来，跟别的装扮不一样。
    手机是动作摆出来的，动作演完必须收回去，手机一收就没东西可换了，
    所以这两条只能演完一起收。想要手机一直举着的话，点「开盖」。

    提一句：眼镜和贴纸（猫猫贴纸、圆方椭圆眼镜、漂浮的问号爱心…）
    虽然也算"道具"，但它们长在脸上，所以归在「表情」那一组里，
    一次只能挂一条。

    少数几条名字后面写着「（模型里没效果）」：那几条是模型作者在
    原文件里就没接上，不是程序的问题 —— 在原版 VTube Studio 里点
    它们也是一样的，什么都不会发生。留着是为了清单完整、方便对照。

    清单最上面是「全部归位」，一键把她身上的表情道具全清掉。
    点花了、不知道开了些什么的时候，点这个就干净了。

隐藏桌宠
    把桌宠收起来。程序还在后台跑，不用重新启动 ——
    再双击一次程序图标，她就回来了。

    （点托盘图标也行，但 Win11 默认把新图标折进隐藏区，
      所以双击程序图标是更稳妥的办法。）

点击穿透
    打开后，鼠标可以直接点到桌宠下面的窗口，她完全不挡路。

    注意：打开之后桌宠就没法拖动、也没法右键了。要关掉这个模式，
    有两种办法 ——

      · 右键屏幕右下角的「托盘图标」→ 取消勾选
      · 按  右Ctrl + 右Shift + P    （任何时候按都有效）

    建议把后面这个快捷键记住。Windows 有可能把托盘图标折叠进
    隐藏区，那时候就只能靠它切回来了。

游戏模式（不响应快捷键）
    打游戏的时候打开它，那 48 个快捷键就全部不响应了。

    为什么要它：她的快捷键是全局的，不分你在用什么软件。
    打游戏时 Alt+字母、Alt+1~4、还有光秃秃一个 E 这些键会一直按，
    她就会在游戏画面上乱做表情。

    打开后她只是不理会键盘 —— 左键单击、待机动作、右键菜单、
    托盘图标全都照常，鼠标点她还是有反应。

    自救的那条快捷键（右Ctrl+右Shift+P 切穿透）不受影响，
    任何时候按都有效。

    注意：这条只管快捷键。打「无边框窗口」模式的游戏时，
    她还是盖在游戏上面 —— 觉得挡就顺手点一下「隐藏桌宠」，
    或者打开「点击穿透」。

始终置顶
    让她一直盖在其他窗口上面。默认就是打开的。

大小
    小 / 中 / 大。默认「中」，约等于屏幕面积的 1/16。

回到右下角
    位置拖乱了、或者拖到屏幕外面去了，点这个一键复位。

开机自启
    勾上以后开机自动启动。默认是关闭的，需要自己勾。

退出
    完全关闭桌宠。


========================================
【任务栏】
========================================

运行后，任务栏上会出现「DS鲸鱼娘桌宠」的图标。

· 右键任务栏图标 →「关闭窗口」  =  退出桌宠
· 右键任务栏图标 →「固定到任务栏」，以后点它就能直接启动

（顺便说明：因为 Windows 的规则，她也会出现在 Alt+Tab 切换列表里。）


========================================
【快捷键】
========================================

有 48 个快捷键，可以让她做各种动作和表情（重锤出击、比耶、
爱心眼、各种贴纸……）。作者手写的清单见《按键表.txt》—— 那份表没把
每一条都列全，最全的一份在右键菜单的「动作」里。

这些快捷键是"全局"的，但不会影响你正在用的软件 ——
按键照常传给当前程序，只是顺带让她做个动作，不会"吃掉"你的按键。

快捷键和右键菜单是同一套规矩：按一条表情会把上一条表情顶掉，
但不会动你已经挂上的装扮（头顶鲸鱼、桌上蛋包饭那些）。

另外还有一条不在上面那份表里，是我们自己加的：

     右Ctrl + 右Shift + P   =   切换「点击穿透」开关


打游戏时上面这些键会一直误触发（尤其是 Alt+字母 和一个 E）。
右键菜单里有一项「游戏模式（不响应快捷键）」，勾上就全部静默，
她不再理会键盘；上面那条逃生用的快捷键不受影响。


========================================
【怎么彻底删除】
========================================

1. 右键桌宠 → 如果「开机自启」是勾着的，先点一下取消勾选
2. 右键桌宠 →「退出」
3. 删掉 DS鲸鱼娘桌宠.exe
4. 删掉这个文件夹：C:\Users\你的用户名\AppData\Roaming\DS鲸鱼娘桌宠

第 4 步是删她的设置（位置、大小这些）。不删也没关系，
就是个几 KB 的小文件，不影响任何东西。

没有安装目录、没有注册表残留（开机自启那一步会自己清掉）。


========================================
【几个小提示】
========================================

· 建议把 exe 放到一个固定的文件夹里，比如
  D:\桌宠\DS鲸鱼娘桌宠.exe，再把快捷方式放到桌面。
  直接放桌面也能用，但桌面文件多了容易误删。

· 她的设置存在
  C:\Users\你的用户名\AppData\Roaming\DS鲸鱼娘桌宠\config.json
  记事本能打开看。删掉它就恢复全部默认设置。
  所以把她放在桌面上，桌面不会多出任何文件。

· 如果把 exe 换了位置，开机自启会失效 ——
  在新位置重新勾一次「开机自启」就好。

· 万一不对劲，上面那个 AppData 文件夹里有两个日志：
      pet.log        —— 她做过什么（启动、每个动作、隐藏/显示）
      pet_crash.log  —— 只有真的崩了才会有内容
  把它们发给分享给你的人，就能查出到底发生了什么。
